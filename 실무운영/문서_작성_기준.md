# 정리 기준 메모

처음에는 작업 메모가 여기저기 흩어져 있어서, 나중에 다시 찾기 쉽도록 폴더만 나눴습니다.
문서마다 반드시 같은 목차를 맞추기보다는, 작업할 때 실제로 다시 볼 만한 내용 위주로 정리하는 것을 기준으로 했습니다.

## 나눈 기준

- `01_리눅스_보안`: OS 기본 설정, SSH, 계정 정책, OpenSSL, YARA
- `02_웹프록시_Nginx`: Nginx 설치, Reverse Proxy, HTTPS, Header 설정
- `03_이중화_장애전환`: Keepalived, PostgreSQL Replication, MariaDB MHA, Redis Sentinel
- `04_DB_운영`: DB 이관, 백업, 문자셋, 감사 로그, 트리거
- `05_배포_CICD`: Jenkins, GitLab, 배포 순서
- `06_쿠버네티스_클라우드`: NCP Kubernetes, Docker, ArgoCD, Ingress
- `07_모니터링_성능점검`: Prometheus, Grafana, Jennifer, NGrinder

## 문서에 남기려고 한 것

- 작업 전에 왜 확인해야 했는지
- 실제로 어떤 순서로 봤는지
- 작업 후 어떤 로그나 상태를 확인했는지
- 다음에 같은 작업을 할 때 주의할 점
