# 문서 작성 기준

실무 운영 문서를 포트폴리오로 정리할 때 사용하는 기준입니다.
단순 설치 기록이 아니라, 운영자가 어떤 배경에서 판단했고 어떻게 검증했는지 드러나는 문서를 목표로 합니다.

## 분류 기준

### 01_리눅스_보안

- OS 기본 설정
- SSH / 계정 정책
- OpenSSL / YARA / 취약점 점검
- 보안 가이드라인

### 02_웹프록시_Nginx

- Nginx 설치 전략
- Reverse Proxy / Upstream
- HTTPS / Header Hardening
- Nginx 보안 점검

### 03_이중화_장애전환

- Keepalived
- PostgreSQL Replication / pg_auto_failover
- MariaDB MHA
- Redis Sentinel

### 04_DB_운영

- DB 이관 런북
- Character Set 정합성
- Audit Log / Trigger
- 백업 전략

### 05_배포_CICD

- Jenkins
- GitLab
- 배포 런북

### 06_쿠버네티스_클라우드

- NCP Kubernetes
- kubectl / iam-authenticator
- Docker 오프라인 설치
- Cloud Function 메모

### 07_모니터링_성능점검

- NGrinder
- Prometheus / Grafana
- Jennifer 알림 설정
- 성능 테스트 결과 요약

## 문서 작성 흐름

```md
# 제목

## 1. 개요
## 2. 작업 배경
## 3. 환경
## 4. 문제/요구사항
## 5. 판단 및 선택 이유
## 6. 적용 절차
## 7. 검증 방법
## 8. 결과 및 운영 효과
## 9. 운영 체크포인트 / 트러블슈팅
## 10. 참고한 원본 문서
```
